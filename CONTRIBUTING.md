# Contributing

Contributions that improve the accuracy, clarity, usefulness, or maintainability of this technical SEO resource are welcome.

## Useful Contributions

Examples include:

- Correcting inaccurate technical guidance
- Improving unclear explanations
- Adding practical audit considerations
- Updating outdated technical information
- Providing reliable supporting sources
- Improving the audit worksheet

## Quality Standards

Contributions should:

- Be accurate and relevant to technical SEO
- Be clearly written
- Avoid unsupported guarantees about rankings or traffic
- Avoid manipulative SEO tactics
- Use evidence or authoritative documentation where appropriate
- Keep recommendations practical and context-aware

## External Links

External references should support the subject being discussed. Do not submit links solely for promotion, backlink acquisition, or unrelated traffic.

## Review

Contributions may be reviewed for accuracy, relevance, clarity, and consistency with the purpose of this resource.

## Disclaimer

Search engines and web technologies change over time. Contributors should avoid presenting temporary implementation details as universal or permanent rules.
