# Security Policy

## Reporting a security concern

Please do not publish sensitive security details, credentials, private URLs, or personal data in a public issue.

If you believe this repository contains a security vulnerability, describe the affected file or behavior, reproduction steps, and potential impact without including secrets. Use GitHub's private vulnerability reporting feature when available; otherwise contact the repository maintainer through the maintainer's GitHub profile.

## Scope

This repository is primarily documentation and checklist material. Security reports should focus on repository code, workflows, or downloadable files that could create a security risk.

The project does not guarantee that every security or privacy risk is identified.
